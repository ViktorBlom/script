# System Health Checker (Python)

## Beskrivning
Detta projekt är ett Python-script som automatiserar insamling av system- och nätverksinformation i en Linux-miljö.
Scriptet används för recon (rekognosering) och ger en snabb överblick av systemets hälsa.

## Funktioner
- Systemhälsa (uptime, minne, disk, CPU)
- Nätverksinformation (IP-adresser och interface)
- Output visas i terminalen och sparas till fil

## Körning
```bash
python3 recon_tool.py
